# Sneaker Ledger V6 Test 0.1

V6 是面向多设备、多淘宝/京东账号采购场景的中央采购账本测试版。

## 第一阶段目标
- 一套中央数据库，不为每个账号复制账本
- 设备只是录入入口，账号是主要统计维度
- 每台设备只显示绑定到它的账号
- 商品支持完整货号 + 快捷码搜索
- 规格预设、数量默认 1、账号/地址自动沿用，减少重复输入
- 多设备采购最终进入同一中央总账
- 离线时采购进入本地待同步队列；恢复网络后自动重试
- 每笔采购由客户端生成 UUID，重复重试不会重复记账

## 数据安全边界
- 不读取淘宝、京东、支付宝、微信或其他 App
- 不保存淘宝/京东/支付密码、验证码、银行卡
- 账号只保存业务昵称；收货地建议只保存“长沙A / 邵阳A”等代号
- 前端只使用 Supabase publishable key
- Supabase public 表全部启用 RLS，匿名角色没有表访问权限
- secret/service_role key 不进入浏览器、不进入 GitHub

## Supabase 数据表
- devices：设备入口
- accounts：淘宝/京东业务账号
- device_accounts：设备与账号多对多绑定
- destinations：收货地标签
- products：商品字典、快捷码与规格
- purchases：采购事实表

## 当前未做
- 淘宝/京东自动读取
- 无障碍/屏幕录制/OCR
- 物流自动同步
- 得物销售/退货/库存事件迁移
- 商品图片云同步

这些功能在快速采购链路验证有效后再评估，避免第一版过重。
