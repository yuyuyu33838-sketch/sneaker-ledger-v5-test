## 0.1.1 安全加固
- 不加载任何第三方 CDN / 远程 JavaScript
- CSP 禁止 fetch / XHR / WebSocket 等对外连接
- CSP 禁止 iframe、object、远程图片和远程脚本
- 用户输入在进入 HTML 前转义，降低 XSS 风险
- 导入完整备份前先做结构、类型、数值和图片格式校验
- 商品图片只接受本应用生成的 JPEG data URL
- 不申请相机、麦克风、定位、通讯录、支付等手机权限

注意：GitHub Pages 同一 `用户名.github.io` 下的多个项目属于同一浏览器 origin。
因此旧项目中的第三方脚本理论上可能访问同 origin 的浏览器存储。
长期应避免旧项目加载远程脚本，或把正式账本放到独立域名/独立 origin。
