# 球鞋账本 V5 Test 0.2

V5 全新测试线，继续与 V4.1 隔离。

## 0.2 主要变化
- 首页改为经营概览：总持仓成本、持仓件数、商品数量、本月利润、今日利润、本月销售到账
- 底部导航固定为：首页｜持仓｜报表｜我的
- 报表新增流水日历，可切换「利润 / 到账」，点日期查看当天流水
- 报表新增近 7 日利润和资金占用 TOP 5
- 卖出改为「单件实际到账 × 数量 = 总到账」，避免多件卖出歧义
- 批量买入可一次录同一商品的多个规格 / 成本 / 数量
- Excel 导入暂时使用 CSV，无第三方 Excel JavaScript 依赖
- 继续使用 IndexedDB、本地图片压缩、完整 JSON 备份与恢复

## 安全边界
- CSP `connect-src 'none'`：V5 Test 0.2 默认禁止 fetch / XHR / WebSocket 等对外网络连接
- 不加载远程 JavaScript、第三方 CDN、远程图片
- 商品图片只存本地压缩 JPEG data URL
- 外部 SKU API 暂未接入

## 下一轮测试重点
1. 首页经营数据是否一致
2. 多批次买入后的移动加权平均成本
3. 多数量卖出：单件到账、总到账、总成本、利润
4. 日历利润 / 到账与当天流水是否一致
5. 批量买入与 CSV 导入是否会破坏库存
6. 备份后清空，再恢复是否能完整重建
